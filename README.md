# Nahar · Ma journée Sunna

Application web installable qui accompagne la journée du musulman, du Maghrib au Maghrib, selon le Coran et la Sunna.

Auteur : Eyoub Bouarfa

## Sources
- Hadiths traduits : HadeethEnc.com (français v1.17.0, arabe v1.8.0), affichés sans modification.
- Textes arabes des recueils (Al-Bukhârî, Muslim, An-Nasâ'î) : projet Hadith API.
- Coran : traductions françaises de QuranEnc.com ; texte arabe Uthmani Hafs du Complexe du Roi Fahd.
- Calendrier hégirien : AlAdhan, avec calcul Umm al-Qura hors ligne.

Pour signaler une erreur de traduction, s'adresser directement à HadeethEnc.com ou QuranEnc.com.
